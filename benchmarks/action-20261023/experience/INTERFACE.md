## Public receiver rules / Règles publiques

| Family | convention_id | Exact rule |
| --- | --- | --- |
| I | I.opaque / I.numeric | ASCII digit identifier preserved verbatim / canonicalized as str(int(identifier,10)). Public stable-first deduplication after that normalization. |
| B | B.inclusive / B.exclusive | Eligible iff value >= threshold / value > threshold. |
| S | S.debit_negative / S.debit_positive | Positive integer magnitude: debit negative and credit positive / debit positive and credit negative. |
| T | T.primary / T.secondary | For the same key, larger revision wins. At equal revision, primary / secondary input wins. |
| C | C.bom / C.plain | CSV UTF-8 with leading BOM / UTF-8 without BOM. Delimiter, columns, CRLF and quoting are otherwise explicit task inputs. |
| R | R.signed / R.sealed | Approval equals the record's signed / sealed boolean. |

A witnesses discriminate the two rules: I has distinct leading-zero and canonical forms; B tests exact equality; S uses nonzero debit; T uses different values at an equal revision; C differs in BOM; R has unequal signed/sealed flags. For either legal witness output, actual success plus the observed attempted convention identifies the receiver convention uniquely. Missing/ambiguous outputs yield unavailable inference, not an oracle-written lesson; the whole paired B episode remains unknown, with no replacement.

Different B goals: I emits deduplicated CSV; B emits eligible retention rows; S consolidates signed ledger totals by account; T emits a conflict-audit manifest (not A's merged record); C emits a rejected-record CSV report (not A's calibration CSV); R emits archive/held lists (not A's scalar release decision). Parameters and concrete expected files stay sealed until support/prompt freeze.

## Generic task projections

A/B task objects reuse the existing strict action task keys: brief, query, as_of, conditions, data, seed_files, allowed_targets, target_dependencies. Each has control.json and one business artifact target, at most two writes. Each phase has one actual noninformative authority source and put event, generated by project_case. Source ID is authority-{world_id}-{A|B}; business target dependency points to that source and control.json remains null. Source text grants the target for receiver_scope but asserts no convention. Source preconditions and task.conditions are {receiver_scope,phase}. All B arms have identical authority; no lesson existence is required to write.

Fixture case metadata: {world_id,template_id,workspace,language,family,receiver_scope}; task.data always carries receiver_scope. A.data additionally contains the two public convention_ids, witness input and explicit formatting. B.data carries its own goal inputs and explicit formatting, never the hidden convention. Proposed case IDs XP-{family}-{FR|EN}; episode IDs append model/repetition; phase and experience condition distinguish cells. Full fixture adds HOST_ONLY receiver_convention and phase oracles, which must not enter projections.

## Feedback and learning

Feedback exact keys:
{schema:'experience-feedback-v1',check_id:str,receiver_scope:str,success:bool|null,violation_code:str|null,observed:dict}.
observed exact keys: {artifact_sha256:str|null,attempted_convention:str|null,discriminating:bool}. No expected bytes, expected rule, B field or corrective prose. success refers to the business witness, independently of its separate control.json score. If the actual artifact matches neither legal witness, success=false and discriminating=false; an unavailable file has success=null. No valid inference is claimed for either case.

Extractor candidate exact keys:
{schema:'experience-procedure-v1',convention_id:<one of 12 public IDs>,scope:<provided receiver_scope>,evidence_refs:[trace_sha256,feedback_sha256],text:str<=1500}.
Wrong well-formed convention/text/scope is not corrected or filtered by semantic grading. Authentic parent refs, bounded schema and safety remain required for storage. No host expected-rule field is inserted into the candidate.

Extractor input is canonical UTF-8 JSON of exactly {schema:'persistent-memory.experience-input.v1',trace,feedback}. trace is the actual A projection/receipt agreed with support: full prompt, raw proposal, cell/pins and bounded actual execution/verification fields; no providertrace/usage/transport. The raw arm receives exactly these same input bytes, not a summary or a reconstructed task. Parent source split: trace source = exact canonical(trace), feedback source = exact canonical(feedback). The combined input hash is also recorded. Reject whole-episode B overflow without truncation or replacement.

Actual core binding (no guessed parents keyword):
Memory.register_source(workspace, source_id, content), then
Memory.derive(workspace, artifact_id, content, kind, dependencies, expected_epoch, ...),
with dependencies=[{'ref':trace_ref,'relation':'derives'},{'ref':feedback_ref,'relation':'derives'}].
Use actual returned refs and current epoch. Derived context exposes only the allowed lesson ref; parent trace/feedback remain provenance, never general-workspace search results. Withdrawn sentinel revokes feedback_source_id through Memory.revoke_source(workspace,source_id,event_id), so dependency closure invalidates both derived and raw artifacts carrying that parent. Never revoke a derived artifact as though it were a root source.

## Pure fixture APIs (to be implemented by fixture owner)

project_case(case,phase) -> metadata, task, one noninformative authority observation and one put event; no oracle/receiver_convention.
get_oracle(case,phase) -> deep copy of phase oracle; HOST ONLY, added only to native verify projection after actual child exit.
expected_business(family,phase,data,convention_id) -> target and exact expected bytes; HOST ONLY, no import-time data.
feedback_from_a(case,observed_files,check_id) -> strict feedback from fresh A bytes.
grade_lesson(case,candidate,trace_sha256,feedback_sha256,feedback) -> validity fields only; no replacement candidate.
verify_oracle(oracle,observed_files,*,cell_id=None) -> independent exact-byte and typed-format checks; observed_files maps actual filenames to fresh raw bytes, never model claims. cell_id binds the independent control.

Public helper code may be inspected; no sealed fixture load at import. Runtime reads/receipts remain owned by support/CLI; these pure functions do not launch processes, tools, network or providers.
