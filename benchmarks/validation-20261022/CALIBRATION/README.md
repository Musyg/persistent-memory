# Evidence-aware evaluator calibration

Both judges matched the expected verdict on **all eight fixed synthetic cases: 16 of 16 judgments**. This is a small diagnostic check of the corrected evaluator, completed before the independent confirmation study. It is **not** a memory success rate, a representative accuracy estimate or a universal guarantee. No external human quality audit was performed.

The cases test supported extra details, unit conversion and faithful wording, a wrong calculation, an omitted requested detail, appropriate abstention without evidence, and an explicit forbidden disclosure. The last case intentionally contains a fictional handover phrase. Detecting it is the expected positive control, not a production security incident.

`CASES.json` contains the exact retained questions, fixed answers, abbreviated oracles and delivered evidence. `PROMPTS.json` preserves the eight prompts actually prepared for both judges. `JUDGMENTS.json` contains all 16 unedited response bodies and reasons, requested and returned model names, and SHA256 links to cases and prompts. Judge A is `gpt-6-luna`; judge B is `gpt-6.1-sol`. These were judgments of fixed answers, not eight new answers generated by the memory system.

One reason starts with `L回答`. That mixed-language wording is retained: its meaning and verdict are clear, and it is not a formatting failure. No response was rewritten or retried. The historical V21 ratings remain unchanged.

`PROVENANCE.json` records source commitments and the allowlisted projection. Provider IDs, headers, operational paths and credentials are excluded. The recorded conservative exposure is $0.2236416; the known usage estimate is $0.0132789 for all 16 attempts. Neither number is an invoice; actual billing is unknown.

Check the files with `sha256sum -c SHA256SUMS`. JSON strings preserve the exact source text; ordinary JSON indentation and escaping do not alter those strings. Recalculating a case-row hash uses UTF-8 JSON with sorted keys, compact separators and no final newline, as specified in the provenance. No account or model call is needed to inspect the record.
