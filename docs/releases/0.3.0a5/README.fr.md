# Noyau 0.3.0a5 : qualification et archives

[English](README.md) · [Reçu](QUALIFICATION.json) · [Empreintes](SHA256SUMS) · [Release](https://github.com/Musyg/persistent-memory/releases/tag/v0.3.0a5)

Le noyau installé et le registre facultatif passent 215 méthodes de test distinctes dans deux environnements Linux, depuis les wheels puis depuis les sources reconstruites. Cela représente 430 exécutions par environnement, 860 au total, sans échec, erreur ou test ignoré. La parité des sources, les imports installés, l'exemple du portfolio et la co-installation sont également vérifiés.

La release reprend les archives exactes d'une construction qualifiée. Après les tests, une erreur du script de laboratoire a interrompu la finalisation des contrôles. Les vérifications restantes sur les sources et les archives ont été effectuées séparément, en lecture seule. L'échec du script reste consigné. Les archives et les résultats d'origine sont inchangés ; les tests n'ont pas été relancés pendant cette inspection.

La documentation contenue dans les archives décrit l'état antérieur à leur qualification. Ce reçu et le dépôt courant en consignent l'achèvement sans reconstruire les fichiers distribués. Le changement conserve le contrat de validation des identifiants et ajuste ses liaisons. Les [mesures appariées](../../../benchmarks/efficiency-20261026/README.fr.md) portent sur la charge synthétique décrite.
